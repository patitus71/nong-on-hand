# ตัวอย่างการใช้งาน calcWorkedTime

```ts
import { calcWorkedTime, formatMinutes } from "./timeCalc";

// เคส 1: ทำงานปกติในวันเดียว 09:00 - 17:30 (ไม่มี OT)
calcWorkedTime(new Date("2026-08-03T09:00:00"), new Date("2026-08-03T17:30:00"));
// -> { normalMinutes: 510, otMinutes: 0 } => "8:30"

// เคส 2: ทำงานล่วงเวลา 09:00 - 20:00 (OT 2 ชม. หลัง 18:00)
calcWorkedTime(new Date("2026-08-03T09:00:00"), new Date("2026-08-03T20:00:00"));
// -> normal 540 นาที (9:00), OT 120 นาที (2:00)

// เคส 3: เริ่มก่อนเวลางาน 07:00 - 18:00
calcWorkedTime(new Date("2026-08-03T07:00:00"), new Date("2026-08-03T18:00:00"));
// -> normal 540 นาที, OT 120 นาที (2 ชม.ก่อน 9 โมง)

// เคส 4: งานข้ามสัปดาห์ ศุกร์ 15:00 -> จันทร์ถัดไป 11:00 (เสาร์-อาทิตย์ไม่นับเป็นงานปกติ)
calcWorkedTime(new Date("2026-08-07T15:00:00"), new Date("2026-08-10T11:00:00"));
// ศุกร์ 15:00-18:00 = normal 180 นาที
// เสาร์-อาทิตย์ = OT ทั้งหมด (ถ้าไม่ต้องการนับเสาร์-อาทิตย์เป็น OT อัตโนมัติ
//   ให้ปรับ logic ให้ skip แทนการนับ OT — ระบุ requirement นี้เพิ่มได้)
// จันทร์ 09:00-11:00 = normal 120 นาที

console.log(formatMinutes(510)); // "8:30"
```

> หมายเหตุ: ตอนนี้ logic ตั้งไว้ว่า "เสาร์-อาทิตย์ทั้งวันนับเป็น OT" ถ้าจริงๆ อยากให้เสาร์-อาทิตย์
> "ไม่นับเวลาเลย" (ไม่ใช่ OT) ให้แก้ใน `calcWorkedTime` ส่วน `isWeekend` ให้ `continue` ข้ามแทน
